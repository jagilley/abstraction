# Operators, Not Footprints

*Domain: representation learning, data, self-modeling, philosophy of language*
*Last updated: 2026-07-02*


## The meaningful primitive in data is the operator (the transformation between states), not the surface trace it leaves; modeling the surface distribution captures a distribution-bound footprint, while modeling the operator captures a distribution-invariant object
*Confidence: moderate*

- The transformation is defined by the *weights* of the generating system (a model's layers, a speaker's mind), so it is invariant to the data distribution; the surface manifold (activations, token strings) is defined by the *data*, so it moves when the distribution moves — [why single models are not enough §9](../why_single_models_are_not_enough.md)
- Single-objective learning fixates on the footprint because the output loss is blind to the *character* of computation and sees only its *quality*: two systems that produce the same surface via a general operator vs. a distribution-specific shortcut generate the same gradient — same source
- The principle has two instances at different altitudes — a model modeling itself, and a model modeling language — that turn out to be the same claim (see children); this cross-level unification is the main reason to treat it as a root rather than a self-modeling detail


### Self-modeling instance: a network's activations are the footprint of its computation; modeling P(activations) captures the manifold (distribution-bound), while a forward self-model captures the transformation g (distribution-invariant)
*Confidence: strong*

- Smoking gun: a forward model (compresses the transformation) has distribution-invariant perturbation robustness across Wikipedia, code, French, math; an autoencoder of identical capacity (compresses the manifold) collapses off-distribution, reaching zero advantage on code — [OOD robustness](../../experiments/a2a_forward/OOD_ROBUSTNESS_README.md)
- Forward prediction is intrinsically cheap because it approximates a weight-defined function, not a data-defined density: H(acts | input, state) ≪ H(acts), which is why a 1–3% self-model suffices where the unconditional GLP needed ~3B params — [activation-to-activation idea](../../ideas/activation_to_activation_forward.md)

See also: [Self-prediction and self-knowledge — transformation vs manifold is the object that must be compressed](self_prediction_and_self_knowledge.md#the-forward-activation-preview-and-backward-synthetic-gradient-roles-produce-distinct-representational-effects)


### Language instance: language is inherently a transition operator on a receiver's state via a shared codebook, not a static data point; autoregressive NTP models transitions in surface-token space (the footprint) and recovers the communicative operator only implicitly and distribution-boundly
*Confidence: moderate*

- Language's design spec is transitional: speech-act theory (an utterance enacts a state change, it does not describe one), Wittgenstein ("meaning is use"), and Rational Speech Acts (an utterance is chosen to shift a listener's posterior over world-states) all define meaning as an operator on a receiver's representation, transmissible only because sender and receiver share a low-capacity codebook
- Autoregressive LMs model P(x_t | x_<t) — a transition over *surface forms*, not over the *state of the agent the utterance acts on*; factoring text probability autoregressively models the operator's shadow on the training corpus, not the operator
- NTP at scale does recover operator structure (theory-of-mind, pragmatics) because the surface was generated by agents applying communicative operators — but only tangled with distribution-specific surface statistics, because nothing in the single objective names the transition; this is the same structural gap as the single-model self-knowledge failure — [why single models are not enough](../why_single_models_are_not_enough.md)
- Testable echo: forward self-models may climb "higher in the DGP" by modeling purer computation (the generative transition operators) rather than surface; RHM (v16m2, where NTP fully encodes the hierarchy) is the intended substrate — future papers[^private], [RHM compositional learnability](rhm_compositional_learnability.md#constructive-implications-curriculum-over-m-not-occupancy-is-the-lever-and-m2-is-a-ready-single-task-deep-hierarchy-substrate)
- Scope: the transition framing is sharpest for dialogic/instructional language (a definite receiver whose state is moved); for decontextualized monologue the "transition in a generic reader" is diffuse, and this is precisely the OOD regime where LLM pragmatic competence is weakest


#### The forward self-model is an intra-agent speech act
*Confidence: speculative*

- Injecting the forward model's predicted-future-activation into the residual stream is a signal that transitions the model's own downstream state, ingested through the same weights it uses for any external input — structurally, an utterance the network makes to itself — [A2A closed-loop](../../experiments/a2a_forward/README.md)
- Same primitive, differing only in scope: language is how one cortex transitions another; the forward model is how a network transitions itself — the inter-agent and intra-agent instances of operator transmission — [cerebellum and cognitive architecture](cerebellum_and_cognitive_architecture.md#the-cortex-can-ingest-cerebellar-predictions-as-native-input--the-grounding-is-the-processing)
