## One-liner

The a2a arc built the cerebellar/**supervised** forward model ("what will happen"), and on RHM even built **one-shot** RL value functions (REINFORCE, a Monte-Carlo critic, value-of-information heads) — but **every value signal it built lifts performance once and plateaus**, because the objective was stationary, the value was either extrinsic-given or injected as a near-inert residual-stream scalar, and it was never placed in a loop that keeps a *moving* frontier open. The missing piece is a **slow, non-stationary, reward-driven *outer* loop** — reward = **learning progress** — that **modulates policy/allocation rather than the residual stream**, the one configuration the repo has the two-timescale *consolidative* machinery for (wake/sleep distillation) but has never put a *value* signal into. This is the meta-RL two-timescale structure (Wang et al. 2018), and it is what makes the looped self-model an *agent* rather than a self-consistent predictor. Four threads in the program — a dark-room concern under cancellation, the calibration null, the still-conflated precision/value gate roles, and value-shaped forecasts beating veridical ones for control — are all the same gap.

## The frame: a value function is a forward model projected onto a scalar

- A **forward model** predicts the full future *state*: `s_t → ŝ_{t+1}` (high-dim, veridical, codomain = state space). This is the a2a FM.
- A **value function** predicts future cumulative *reward*: `s_t → E[R | s_t]` (scalar, evaluative, codomain = ℝ). It is the forward model **read out through the reward dimension** — the same future, collapsed onto one axis.

This gives a principled reading of why value functions are peripheral to the a2a phenomenology. The program's most durable finding is **direction, not magnitude**: `r(res, LM) ≈ 0` at every capacity; self-knowledge lives in the residual's high-dim *direction*, not its scalar *norm*; magnitude/norm-direction steering is causally inert ([CAUSAL_PROBES_README.md](../experiments/a2a_forward/CAUSAL_PROBES_README.md)). The value function is a *scalar* readout — and the program keeps finding scalar summaries are the weak metric.

**This immediately constrains how the value signal must enter** (a tension the audit flagged, and the resolution the program's own data forces): a scalar `V(s)` *injected into the residual stream* is exactly the kind of scalar the system treats as inert — and indeed the repo already saw this ([EMOTION_INJECTION](../experiments/a2a_forward/EMOTION_INJECTION_README.md), below). So value must act as a **drive over policy/allocation** (modulatory), not as an added activation-space scalar; and the *useful* value signal is a low-dimensional **direction** (the value-relevant slice of the forecast), not a magnitude. "Value = the scalar collapse" is the conceptual identity; operationally it is a policy drive read off a value-relevant direction.

### Cancellation is a *different* projection than value-projection — the value signal hides in the gap

[efference_copy_cancellation.md](efference_copy_cancellation.md) subtracts the **forecast** `p` (high-dim predicted next state) and propagates `e = h − p` (surprising activation content): a predictable-vs-surprising split of the **computation**. The **value scalar** is a 1-d readout along a *reward* axis — a different object. The honest statement: **the value axis was never in the a2a objective to project out.** The right decomposition is three-way:

```
forecast p  =  value-relevant direction  ⊕  predictable-but-value-irrelevant  ⊕  (residual e = surprise, the part cancellation propagates)
```

Cancellation splits off `e`; it does not separate the value-relevant direction from the rest of `p`. That missing split is what carries control: on ground-truth latents, [ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md) found a high-fidelity mean-Δ forward model is a **planning null** and raising its fidelity bought *zero* planning, while a **value-of-information head** (expected posterior entropy — an intrinsic epistemic value) converted the null into a decisive planner. The value direction lives inside the forecast; the planner runs on *that* slice, and full-state veridicality is the *worst* substrate.

## Four threads, one missing piece

### 1. Dark room — a self-directed agent needs a drive cancellation doesn't supply

Cancellation's fixed point is `s* = FM(s*)`: minimal prediction error. In a *generative/self-directed* setting that is an attractor toward *predictable* states — the dark room (Friston), whose standard resolution in the predictive-coding literature is a hardcoded prior over preferred states, i.e. a value function. The a2a program's only counter-drive so far is the **task loss** (NTP/classification), which is *extrinsic-given* and evaporates the instant the agent self-directs (choosing where to glimpse / where to reach has no per-step task reward).

*Honest caveat (pre-control evidence).* The looped empirics do **not** yet show a strong dark-room attractor: the plain loop never settles (~15% from a fixed point), the causal action lives in the *transient*, the forecast behaves "more like a trajectory the model organizes around than a fixed point it settles into," and the self-regulated gate sits at a ~2% dose ([LOOPED_README.md](../experiments/a2a_forward/LOOPED_README.md)). So the dark room is a **prediction about self-directed control**, not an established pull in the perception loops measured to date. It is precisely the control setting that would make it bite.

### 2. Calibration is a value-function property, not a forward-model property

Three maps: FM = `s → ŝ_{t+1}` (state space); value = `s → E[R]` (scalar); **calibration = `s → P(output correct) = E[correctness | s]`**. Correctness is a *reward*, so **calibration is literally a value function whose reward is "was I right."** It cannot be read off the FM: the FM's codomain is next-state not expected-correctness (wrong type); its training signal never references whether the *final answer* is right (predict the next activation perfectly and still be wrong); and even a probabilistic FM's variance is calibrated to *state-transition* uncertainty, not *task-outcome* correctness.

The cleanest empirical anchor is the mechanistic one, not the raw null: [REPRESENTATIONAL_DIVERGENCE](../experiments/a2a_forward/REPRESENTATIONAL_DIVERGENCE_README.md) (Prediction-Trust) states that self-knowledge "lives in **computation-space** (which parts of my transformation are novel), not **outcome-space** (will I get the next token right) — a scalar loss-calibration probe was looking in the wrong space," and shows the FM is the **unbiased conditional mean** (Wiener gain ≈ 1) with the self-knowledge in the *second moment* (innovation covariance) — i.e. the value/outcome readout is a *further* projection the FM never carries. [OOD_ROBUSTNESS](../experiments/a2a_forward/OOD_ROBUSTNESS_README.md) Exp A (closing the loop gives computational but not epistemic self-knowledge; output entropy beats every activation probe) is supporting evidence — with its own hedge that "the calibration null might look different at scale" (29M/10M is frequency-dominated), so the *type-theoretic* argument, not the small-scale null, is the structural claim. (Ilya's teenage driver "already has a sense of how badly they are, how unconfident" — that self-evaluation is `V`, not the forward model of the car.)

### 3. Two gate *roles* the biology separates — and which one the repo already has

Biologically there are two gating roles: a **thalamic error-relay** (which part of the signal to *transmit forward*) and a **brainstem value/drive** (whether a state is *worth pursuing/learning*). The a2a arc has repeatedly built gates, but naming them as one "precision gate" was a mistake, and the direction was wrong:

- **The error-relay role = propagate the unpredicted residual — and it *amplifies*, it does not discount.** [REPRESENTATIONAL_DIVERGENCE](../experiments/a2a_forward/REPRESENTATIONAL_DIVERGENCE_README.md) (Prediction-Trust) measured whether the injection's learned gain tracks FM reliability and found the gain points **at** the directions where the FM habitually errs (r=+0.60) and **away** from where it is reliable (r=−0.34): "the naive discounting account is falsified by sign." This is consistent with the biology (the thalamic relay *amplifies error* in burst mode; [cerebellum_and_cognitive_architecture.md](../beliefs/trees/cerebellum_and_cognitive_architecture.md)) and with Rao–Ballard error units — and it is the same thing as **cancellation** (transmit the prediction error). So the error-relay role is real and the arc has it; "close where the forecast is unreliable" was simply the wrong sign.
- **"Close on globally poorly-predicted inputs" is a *separate, untested* pressure.** [CANCELLATION](../experiments/a2a_forward/CANCELLATION_README.md) Payoff 4 establishes only a **loss-landscape asymmetry** (subtracting a wrong forecast hurts, +0.136 → −0.148) — the README is explicit that the *gate dynamics* are untested and the resting gate is unchanged (~0.017). So this is *endogenous pressure*, not a demonstrated gate. (Earlier drafts of this doc overstated it as "the precision gate for free" — corrected.)
- **A value/competence gate already exists, first-order.** [OOD_GATE](../experiments/a2a_forward/OOD_GATE_README.md)'s NTP-trained unified gate **closes on competent (known) inputs and reopens on novel ones** ("inject less where already good") — a competence signal dissociable from FM-error (r≈0.10). So "the value gate is still to build" is too strong. What is missing is the specific thing: a **learning-progress-rewarded, non-stationary, slow-timescale** drive over *policy*, not a per-input injection-utility gate.

*Caveat (pre-control).* All of the above was measured on perception tasks, before the shift to control. The "gate that worked" in [MNIST_LOCAL_LOSS](../experiments/a2a_forward/MNIST_LOCAL_LOSS_README.md) is a bilevel weighting of the *auxiliary local loss* (a within-loss credit-assignment weight), and its FM-error-independence is regime-specific (a smaller-FM ratchet gate anti-correlates with FM error, −0.55 to −0.79; [GATED_RATCHET](../experiments/a2a_forward/GATED_RATCHET_README.md)). Whether a value/drive gate over *actions* behaves differently is exactly what a control task would test. **Terminology fix:** [REACHING_INTERNAL](../experiments/a2a_forward/reaching/REACHING_INTERNAL_README.md) already uses "thalamic-relay projection gate" for `CerebellarGate` in a *reading/transferability* role — a different gate; this doc uses **error-relay** (transmission) and **value/drive** (motivation) to avoid the collision.

### 4. Value-shaped forecasts beat veridical ones for control — a meta-RL signature

[ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md): a mean-Δ forecast is a planning null and higher fidelity buys zero planning; a decision-variable (VoI) head is decisive. [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md): a value-shaped co-trained FM is the *best* planner substrate (+0.51) despite the *worst* veridicality, beating even a perfect simulator (+0.33). In meta-RL, the inner-loop dynamics are shaped by the *outer-loop value*, so the inner-loop forecast becomes value-shaped, not veridical. The program observed the signature without naming it.

*Anchor honesty.* The value doing the shaping in [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) is a **hand-coded extrinsic** goal-distance (`value(s) = −E[dist(pos, g)]`) — the same extrinsic-given signal §1 says is only a partial patch, and the README frames it as division-of-labor/gauge, not meta-RL. So [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) is evidence that *value-alignment > veridicality for control*, not that *learning-progress* or a *frozen-evolutionary* value does the work. [ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md)'s VoI head — an *intrinsic epistemic* value — is the better anchor for the intrinsic case.

## The hardcoded prior over preferred states = learning progress (not raw novelty)

The value is not over specific states (evolution can't name them) but over a **functional of the forecast dynamics: learning progress** `−d‖e‖/dt`. Naive *maximize surprise* hits the **noisy-TV problem** (fixate white noise forever); *minimize surprise* is the dark room. The program already wrote this down: [GATED_RATCHET](../experiments/a2a_forward/GATED_RATCHET_README.md) — "the dopamine system may track the **derivative** of the FM residual — rapid decrease = rewarding; residual near zero = boring; **high static residual = frustrating**" (that last is the noisy-TV case). And [RHM_LATENT_LOOP](../experiments/rhm/RHM_LATENT_LOOP_README.md) restates the correction in RHM's own terms: i.i.d. *sample*-novelty is unlimited yet the frontier stays pinned — "the curiosity signal should select harder **targets/levels**, not novel samples."

**The reducible-vs-noise discriminator is a fresh-FM ensemble, not rank.** An earlier version of this doc mapped "high-rank = noise, low-rank = learnable" — a category error. The program's finding is that residual **rank reflects DGP *complexity*, and all of it is learnable** (language's residual is full-rank 200/256 yet the FM captures it to cosine 0.97 — genuine distributed computation, not noise; [MNIST_README.md](../experiments/a2a_forward/MNIST_README.md) / [README.md](../experiments/a2a_forward/README.md)). We had incorrect early intuitions about FM-residual rank; rank ⊥ noise. The right instrument is the **fresh-FM ensemble** ([RHM_COMPLEXODYNAMICS](../experiments/rhm/RHM_COMPLEXODYNAMICS_README.md), [RHM_LATENT_LOOP](../experiments/rhm/RHM_LATENT_LOOP_README.md)): it separates an FM-*idiosyncratic* "scaffolding" residual (trajectory-owned, disappears — observer noise) from a **DGP-aligned floor** (problem-owned, every FM misses it identically — reducible structure). A learning-progress reward must chase the reducible component; the ensemble is what tells them apart. So the criterion is `−d‖e‖/dt` **on the ensemble-invariant (reducible) residual**, never raw magnitude or rank.

| regime | `‖e‖` | `d‖e‖/dt` | reducible (ensemble-invariant)? | value |
|---|---|---|---|---|
| dark room | ≈0 | ≈0 | — | low |
| noisy TV | large | ≈0 | no (FM-idiosyncratic) | low |
| learnable frontier | moderate | large | yes (DGP-aligned) | **high** |

## Meta-RL: the two-timescale structure — and why non-stationarity is the load-bearing part

Wang et al. (2018), "PFC as a meta-RL system": a slow dopaminergic **outer loop** trains a recurrent network that implements its own faster **inner loop**. Mapping onto the program: the looped ViT + FM injection = the inner loop; the wake/sleep **distillation ratchet** = an existing two-timescale scaffold ([DISTILLATION](../experiments/a2a_forward/DISTILLATION_README.md); multi-cycle [GATED_RATCHET](../experiments/a2a_forward/GATED_RATCHET_README.md); [OOD_GATE](../experiments/a2a_forward/OOD_GATE_README.md) Exp 4 — compounding generalization, 48% val gap, +8pp zero-shot OOD). **The machinery exists; its outer loop is consolidative/legibility-driven, not reward-driven.** Putting a *value* signal into that slow loop is the contribution.

**Non-stationarity, not the two-timescale structure per se, is what's missing.** [RHM_META_LEARNING](../experiments/rhm/ratchet/RHM_META_LEARNING_README.md) ran five meta-learners (FOMAML/Reptile) over a **stationary** objective and *all collapsed to plain multitask* — no compositional-transfer gain, because "the outer loop is identical to the inner loop." [RHM_SCULPT_CONTINUAL](../experiments/rhm/RHM_SCULPT_CONTINUAL_README.md) is the same story from the value side: value-iteration is the big lever (+0.25) but the plannability frontier **saturates in one pass** on fixed data. So a two-timescale value loop over a fixed task provably manufactures nothing here — the reward must track a **moving** frontier (learning progress selecting harder targets), which is the whole point.

## Non-stationarity, sharpened (2026-07-18): two kinds, what makes a value *meta*, and the learning-vs-meta layer split

Three refinements from a 2026-07-18 discussion, all pivoting on the non-stationarity the section above names as load-bearing. Recorded because they reorganize the frame.

**(a) A value function is not meta-learning; what makes LP *meta* is that its reward is second-order.** Every value the program built before curiosity was **value in the *inner* loop** — goal-distance ([REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md)), the VoI head ([ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md)) — a functional of the *state* `s`. That is the **somatic-marker / single-loop (map)** form (§ below): an amortized cache over the experienced distribution that *looks* meta (it amortizes over a distribution) but is the **non-meta** case by construction — no second loop asks whether the cache transfers. Learning progress is genuinely meta not because it is a value function but because **its reward references the learning dynamics** (`−d‖e‖/dt`, a competence *derivative* — second-order, a functional of the model's own competence trajectory rather than of the state). So "we used value functions all along, so we were always a bit meta" mistakes a cache for a meta-loop. The one true meta-RL *signature* present pre-curiosity is [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) Finding 2 (value-shaped forecast ≻ veridical) — but that is *the inner loop being shaped by a value*, not *learning to learn*; the genuinely-absent ingredients were the **competence-derivative reward** and **non-stationarity**.

**(b) Two kinds of non-stationarity — and abstraction-climbing is the evolved *solution* to the second, not a subset of it.** The program's "moving frontier" is two distinct objects:
- **Type-1 (epistemic / frontier):** the DGP is *fixed*; your *knowledge* of it moves — climbing the RHM depth tree. The non-stationarity is internal (it *is* learning progress) and **self-terminating** at the DGP ceiling (Jasper's ratchet note: a moving frontier "up to and until it hits its ceiling, and no further"). This is why the RHM ratchet never compounds ([RHM_META_LEARNING](../experiments/rhm/ratchet/RHM_META_LEARNING_README.md)) — Type-1 runs out.
- **Type-2 (environmental / aleatoric):** the *DGP itself* changes — `curiosity_drift`'s morph/swap, which had to be **engineered** because active vision is stationary in its dynamics. Unbounded: the world re-opens the frontier forever.

The hierarchical-tree framing of continual learning (climb the infinite tree, expand effective dimensionality) is the **Type-1 special case** — the finite one; biological meta-learning is Type-2. But the two are **not nested**: abstraction-climbing (Type-1) is the machinery evolution built *for* Type-2, because higher hierarchy levels are *more invariant under shift* (the specialization line's shared/transferable deep structure, "broad beats narrow" — [../experiments/rhm/specialization/README.md](../experiments/rhm/specialization/README.md)). You climb toward abstraction *because* abstract invariants are what survive a changing environment. So "intellectual" continual learning is **not a subset** of environmental adaptation but the **same machinery exapted** onto culturally-constructed abstraction hierarchies (math, science); its non-universality in humans (needs schooling as scaffolding) is the exaptation tell. This gives LP its evolutionary rationale: **LP is a bet on non-stationarity** — invest in reducible structure now because invariants pay off under future shift — which is *why* a stationary Phase 1 makes LP *exhaust* (no future shift to hedge against).

**(c) Learning layer vs meta layer — the FM lives in the learning layer.** Meta-learning is necessary **iff** the world is non-stationary: on a stationary objective it provably manufactures nothing ([RHM_META_LEARNING](../experiments/rhm/ratchet/RHM_META_LEARNING_README.md): five meta-learners collapse to plain multitask, "the outer loop is identical to the inner loop"). So meta-learning is **not intrinsic to cognition** — it is *imposed by* (b). Two layers follow:
- **Learning layer** (cerebellum + cortex): the supervised FM, the composable simulator, computational self-knowledge — the inner loop. **The whole reaching arc lives here**: arity-2 FM, deep composition ([REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) Finding 1), and value-shaped control (Finding 2) were all achieved on **stationary** tasks with **no outer loop**. The curiosity line is logged as "a distinct thread" precisely because it is the one that must *engineer* non-stationarity — it is the meta layer.
- **Meta layer** (basal ganglia / brainstem prior / PFC): the slow reward-driven outer loop; earns its keep only under Type-2.

Two refinements keep the split from being too clean: (1) the FM *mechanism* is learning-layer, but its learned *content* is **value-shaped by the meta layer** ([REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) Finding 2 — the meta-RL signature) — which is *why* the cerebellum↔PFC/VTA connections exist: they are the **interface** between layers ("the FM is the substrate; the value tag is a low-dim readout the midbrain attaches"), not evidence the FM sits in the meta layer. (2) **Self-knowledge straddles**: *computational* self-knowledge ("which parts of my computation are novel") is learning-layer and the loop delivers it; *epistemic* self-knowledge / calibration ("will I be right") is outcome-space = meta layer, and the loop does **not** deliver it ([OOD_ROBUSTNESS](../experiments/a2a_forward/OOD_ROBUSTNESS_README.md) Exp A: computational but not epistemic) — discriminator 2 (calibration-recovered-OOD) is exactly the meta layer buying back the half the loop can't.

**The clean predictive handle this yields — already borne out:** **value-shaping ∈ learning layer** (achievable stationary — [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) +0.51, no meta loop) vs **compounding ∈ meta layer** (requires non-stationarity — absent stationary, [RHM_META_LEARNING](../experiments/rhm/ratchet/RHM_META_LEARNING_README.md)). Both halves already landed on the predicted side.

## The interface shape (2026-07-18): two afferent taps + one efferent gain — and what to test next

Double-clicking on the FM↔value interface (c refinement 1): the value system does **not** read the FM's whole state — *which part it taps* determines the function. Read off the three-way decomposition `h = value-relevant(p) ⊕ value-irrelevant(p) ⊕ e` (§"Cancellation is a different projection").

**Two afferent taps (FM → value), and they are exploit vs. explore.**
- **Exploit = value off the forecast `p`** (its value-relevant slice): "of what I can already foresee, which is best?" → act toward it. Anchor: [ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md)'s VoI head plans where full veridicality is a null.
- **Explore = value off the residual `e`** (its *reducible* part): "where am I still failing to predict, learnably?" → go learn there. Anchor: the curiosity LP drive.

So **explore/exploit falls out of which part of the FM's output the value system taps** — the not-yet-predicted-but-learnable `e` vs. the already-predicted value-slice of `p`. This sharpens open-question #1 from "read `p` *or* `e`?" to "**both — and they are the two drives.**"

**One efferent gain (value → FM): value-shaping = capacity *re-allocation*, not injection.** The FM has limited capacity; value re-prioritizes *which* directions of `p` it spends that capacity getting right — sharpening the value-relevant subspace at the cost of veridicality on the value-irrelevant part (a worse literal simulator, a better planner). This is [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) Finding 2 (value-shaped +0.51 ≻ a *perfect* sim's +0.33). *Boundary condition* (MuJoCo, [META_ADAPT §Cut #4d](../experiments/mjc/meta_adapt/README.md#cut-4d--value-shaping--meta-conditioning-two-separable-capacity-levers-and-when-re-allocation-buys-control-meta_value_shapingpy)): the *worse-simulator* half holds unconditionally, but the *better-planner* half appears **only under capacity competition** — value-shaping is control-*neutral* when the value-irrelevant subsystem is capacity-decoupled (dropping it is then free but unrewarded). It **adds nothing to the representation** — it is a priority field over prediction targets (a "spotlight"), consistent with [EMOTION_INJECTION](../experiments/a2a_forward/EMOTION_INJECTION_README.md)'s additive-scalar-into-the-stream being inert.

**Functional shape of the tag** — three properties, each with toy-task support:
- **Band-pass on the residual** — the §regime table made mechanistic: ~0 at `‖e‖≈0` (mastered / dark room), ~0 at large-but-static/irreducible `‖e‖` (noisy TV), peak at moderate-and-*falling* `‖e‖` (frontier). Support: [curiosity](../experiments/a2a_forward/reaching/CURIOSITY_DRIVE_README.md) Phase 1 (surprise→noise, min-surprise→blank, LP→middle-then-release).
- **Reducibility-filtered spatial field** — a per-location heatmap of "learnable-here," computed by **ensemble disagreement** (a committee of FMs disagrees on learnable-but-unlearned structure, agrees on both mastered *and* pure-noise regions). Support: Phase 2b (disagreement over-samples the needle 3.7×→8.5×). Nuance: single-model LP is a *quantitative*, not qualitative, loss — the ensemble helps, isn't strictly required.
- **Multiplicative / gating, not additive** — value modulates existing signals up/down (spotlight), it does not sum in a value vector. Support: additive-inert ([EMOTION_INJECTION](../experiments/a2a_forward/EMOTION_INJECTION_README.md)); multiplicative gates worked throughout the arc.

**Honest status — a triangulated *prediction*, not an established mechanism.** Each *ingredient* has toy-task evidence (band-pass drive, disagreement filter, value-shaping ≻ veridical, gating ≻ injection, forecast-slice control); the *recipe* — the two taps wired as one explore/exploit interface, driven by an outer loop that *causes* the shaping — is unbuilt. **The next pieces to test, in order:**
1. **The `e`-tap and the `p`-tap are one system** — build both on one control substrate; show they trade off as explore/exploit (resolves open-Q #1 empirically).
2. **An outer loop *causes* the shaping** (discriminator 4) — [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md) got value-shaping from co-training a *hand-coded* value; wire a slow reward-driven loop and show the shaping is *caused* by it, not hand-designed in. **Partly landed** ([META_ADAPT §Cut #4d](../experiments/mjc/meta_adapt/README.md#cut-4d--value-shaping--meta-conditioning-two-separable-capacity-levers-and-when-re-allocation-buys-control-meta_value_shapingpy)): a value-*support*-weighted objective (the re-allocation *derived from* the goal-reaching value, not tuned) produces a dissectible re-allocation that buys control under capacity competition (4 seeds) — still-open piece is the reward-*driven* loop proper (backpropped control performance / a slow reward), vs #4d's supervised support-weighting. **Now closed** ([META_ADAPT §Cut #4e](../experiments/mjc/meta_adapt/README.md#cut-4e--closing-the-reward-loop-the-value-shaping-is-caused-by-reward-meta_value_learnpy), 2026-07-19): the per-dim FM weight is chosen by an outer loop whose *only* signal is control performance (−CEM-MPC goal distance), no support hint — and reward *reconstructs* the shaping. Reward **prefers** the puck-drop (landscape) *and* a free CEM loop **rediscovers V's support** (converged-allocation corr→support +0.39±0.04, 3 seeds), even up-weighting the value-relevant dims beyond the hand mask — **only under capacity competition** (matched-null flat on the easy pusher). Two transferable gotchas: (i) normalize the weight to a fixed budget or the loop games *loss-scale* not *allocation* — a concrete instance of the wireheading control, the fixed budget being its "on-manifold veto"; (ii) read the optimizer's *converged distribution*, not its selection-biased single-best. Still a rung short of the **fully-online** single two-timescale loop (reward continuously shaping a *live* FM, vs an outer optimization over retrained FMs).
3. **Ensemble-disagreement as the online reducibility proxy** — does the disagreement *magnitude* substitute for the fragile `−d‖e‖/dt` *derivative* per-step (open-Q #2), removing the re-opening blindness Phase 2 exposed?

## Biological grounding

Doya's two teaching systems (already in [cerebellum_and_cognitive_architecture.md](../beliefs/trees/cerebellum_and_cognitive_architecture.md)): cerebellum = supervised ("what will happen"), basal ganglia = RL ("was that good"), dopamine. The a2a arc is the cerebellar axis. The bridge the tree gestures at — "cerebellar prediction errors may modulate dopaminergic signaling via VTA projections" — is a concrete **cerebellum → VTA** pathway (Carta, Regehr et al., *Science* 2019, as recalled) **specifically required for social-reward behavior**: exactly "social supervision done in a value-function-like way." Anatomy precision (sharpening the prompt's hunch): the **pons** is the *input* relay (cortico-**ponto**-cerebellar, hindbrain, = the FM's compression); the **thalamus** (VL) the *output* relay; the **VTA** (midbrain) the value nucleus that both projects to and receives from the cerebellum. The forward model is the *substrate*; the value tag is a low-dim readout the midbrain attaches. **Complexity-robustness tradeoff** (Ilya): the frozen low-dim value prior is robust and general *because* simple; the high-dim FM is capable but brittle — matching [OOD_ROBUSTNESS](../experiments/a2a_forward/OOD_ROBUSTNESS_README.md)'s "computational, not epistemic; distribution-invariant." Damasio's somatic-marker patient (the stroke case Ilya cites) is the value-lesion: intact forward model, absent value function, cannot decide.

### The somatic marker is the single-loop (map) form of the value function — and its failure modes are the case for the bilevel loop

Damasio's **somatic-marker hypothesis** (the theory behind the patient Ilya cites) *is* primitive 2, in its **amortized/cached** form. A somatic marker is a fast learned association `situation-features → good/bad bodily state` that **pre-prunes the option space** before deliberate cost-benefit analysis — Ilya's "value function short-circuits the wait until the end." In this doc's vocabulary it is a **map, not a model**: an absorbed direct readout, not a runnable re-derivation. Its power — the speed and pruning the vmPFC patient conspicuously lacks — comes precisely from *being* a cheap cached correlation rather than a forward simulation.

That cache is exactly where **spurious correlations** live. A value map learned in a *single* loop absorbs whatever correlates in the experienced distribution — spurious associations included — because there is no second loop asking whether those associations *generalize*. This is the same failure as traditional-ML overfitting to training-distribution correlations, and it has concrete phenomenology: **phobias, trauma associations, superstition, and addiction are spurious somatic markers** (a bodily valence wrongly bound to a stimulus that isn't actually good/bad), and their "cure" (exposure therapy / CBT) is *re-running the loop with new evidence to overwrite the marker* — a slow deliberate stand-in for the missing meta-loop.

The sharpening that ties this to the non-stationarity thread: **the spuriousness is invisible in-distribution and manifests only under shift** — the diagnostic signature of single-loop learning. The Iowa Gambling Task shows the good side (anticipatory skin-conductance responses to bad decks *before* conscious knowledge) precisely *because the task is stationary*; swap which decks are bad and the cached markers would lag and mislead. This is the same result as [RHM_META_LEARNING](../experiments/rhm/ratchet/RHM_META_LEARNING_README.md): a stationary single loop cannot separate causal from spurious because its train and eval distributions coincide. **The bilevel outer loop is the fix exactly because it evaluates the value on a *shifted* distribution, selecting associations that transfer (causal) over ones that merely correlate (spurious).** Two error sources fall out, both distribution-shift of an un-re-evaluated value: (1) the lifetime loop overfitting your own experience (phobia); (2) the frozen evolutionary prior gone *stale* (snake fear, hunger-in-abundance — Ilya's own example) — not "never causal," but out-of-distribution now.

Resolution, and why it argues *both* loops are load-bearing: the fix is **not** to delete the fast marker — the vmPFC patient proves removal is catastrophic (endless undirected deliberation) — but to pair it with a slower, model-based loop that can *override* it when it is wrong. Fast cached value (spurious-prone, necessary for pruning) + slow re-derivable value (robust, corrective) is the inner/outer, System-1/System-2 structure. The somatic marker is what a value function looks like with only the inner loop; its pathologies are what the second loop buys back.

## The experiment: put learning-progress value in the slow loop of a *control* task

The value function only earns its keep where **acting ≠ planning** ([ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md) Phase 4: internalization is redundant on inference-in-disguise tasks, load-bearing on control). This also disarms the two pre-control nulls: [EMOTION_INJECTION](../experiments/a2a_forward/EMOTION_INJECTION_README.md) found a value head injected into the residual stream nearly inert — but that was a *perception* task with no room for value to steer behavior, and its own conclusion was that value is *modulatory over allocation*, not a residual-stream restructurer. A control task with value **driving the policy** is exactly the setting it said it couldn't test. Likewise the pre-control precision-gate results (§3) may not transfer.

Two viable substrates — try either or both:

- **RHM sculpting** ([RHM_SCULPTING](../experiments/rhm/RHM_SCULPTING_README.md)) — the *controlled* option. Ground-truth latents give a **native learning-progress signal**: the per-level probe-accuracy "traveling wave" is `‖e‖` per hierarchy level over training, so `−d‖e‖/dt` per known level is directly computable; the **fresh-FM ensemble** separates reducible from noise; **`m=2` vs `m≥4`** is a built-in frontier-climbing-vs-stalled dial (validates that learning-progress fires only where structure is reducible); a working MC value `V(z, r*)` is already there to graft onto; and the pre-registered non-stationarity test ("introduce a deeper L / fresh rule set — does the ratchet re-open?") is ready.
- **MNIST reaching** ([REACHING_INTERNAL](../experiments/a2a_forward/reaching/REACHING_INTERNAL_README.md) / [REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md)) — the *simpler* option, and a near drop-in: it already runs a value-driven MPC loop (`a = argmax_a value(s + FM(s,a))`) and shows the value readout causally reorganizing the operator to be plannable (`int_plan`). The minimal change is to **replace the extrinsic goal-distance value with learning-progress** `−Δ‖e‖` and add the noisy-TV control.

Common design (both substrates):
- **Inner loop (fast)**: the looped forward-model policy already built (recurrence + FM + the error-relay/cancellation wiring).
- **Outer loop (slow, partially frozen)**: a value head trained on **intrinsic reward = learning progress on the reducible residual**, **driving the policy/allocation** (where to reach / which target-level to pursue), *not* injected as a residual-stream scalar. Freeze/slow it relative to the inner loop to instantiate the two timescales and the evolutionary-prior/lifetime-learner split.

**Discriminators** (each targets one thread):
1. **Dark room broken**: value-driven action explores reducible structure; a curiosity-free (task-only) policy collapses onto trivially-predictable actions. Requires an exploration-forcing geometry (occluded-reveal reaching; a deeper RHM level).
2. **Calibration recovered**: the value head's `E[correctness | s]` transfers OOD where FM activation probes did not ([OOD_ROBUSTNESS](../experiments/a2a_forward/OOD_ROBUSTNESS_README.md) Exp A is the baseline; [EMOTION_INJECTION](../experiments/a2a_forward/EMOTION_INJECTION_README.md)'s value head *degraded to negative R²* in-distribution — a bar to clear).
3. **Two roles separable**: the error-relay (amplify unpredicted residual) and the value/drive (pursue reducible-progress states) respond to different axes — construct high-reliability/low-progress vs low-reliability/high-progress states.
4. **Value shapes the inner loop**: under the outer-loop value the inner forecast becomes more value-relevant and less veridical ([REACHING_LOOKAHEAD](../experiments/a2a_forward/reaching/REACHING_LOOKAHEAD_README.md)/[ACTIVE_RHM](../experiments/rhm/ACTIVE_RHM_README.md)), now *caused* by the outer loop.

**Two controls that are not optional:**
- **Noisy-TV**: reward must be `−d‖e‖/dt` on the **ensemble-reducible** residual, not raw `‖e‖`. Add an irreducible-noise region (a static/random RHM sub-rule; a noise patch in reaching); a surprise-maximizer fixates it, a learning-progress agent leaves once `d‖e‖/dt → 0`.
- **Wireheading**: [RHM_EDIT_CONTROL](../experiments/rhm/RHM_EDIT_CONTROL_README.md) showed a value collapsed onto a belief scalar `P(root=r*)` gets *gamed off-manifold* (planning drives `P(r*)→1` while ~99% of sequences go off-grammar) — fixed only by an **on-manifold self-consistency veto**. Any learned value here needs the same grounding, or it hacks its own reward.

## Results (2026-07-17): the curiosity-drive line

Ran a **minimal** version of the drive atom on **active vision** (full writeup: [CURIOSITY_DRIVE_README](../experiments/a2a_forward/reaching/CURIOSITY_DRIVE_README.md)) — a content-query world model + a teleport policy allocating glimpses by an intrinsic reward, drives differing only in that reward (`lp`/`surprise`/`minsurprise`/`random`, + an ensemble `disagree` in Phase 2b). Scoped down from the full plan: **no learned value head** (drives act on the *true* current reward — isolates "what each drive prefers"), **no recurrent belief loop** (a content-carrying belief *leaks*: it lets the WM predict re-glimpsed noise, faking LP — so it was dropped; deferred to a value-shaping phase), and **no internalization** yet.

**Substrate correction (supersedes "near drop-in on either" above).** Chose active vision over RHM because the RHM **specialization line** ([../experiments/rhm/specialization/README.md](../experiments/rhm/specialization/README.md)) shows the RHM depth frontier is **not moved by *allocation*** (breadth-restriction inert, level-reweighting harmful; only a *direct deep target* moves it) and the root is never NTP-supervised — so an allocation-driven curiosity signal has no lever there, and an `LP≈uniform` result would be a *confounded* null. The "native learning-progress traveling wave" is real but is *not allocation-steerable*, which is what the outer loop needs.

**What the three phases established:**
- **Phase 1 (drive atom) — clean positive.** On a stationary struct/noise/blank arena, both non-optional controls behave as predicted: **surprise fixates the irreducible noise** (noisy-TV), **min-surprise collapses to blank** (dark room), and **LP alone rides the reducible frontier then *releases* it** once mastered. So **LP ≠ raw surprise** (the noisy-TV falsifier — *not* falsified: they diverge cleanly) and **LP ≠ predictability-seeking** (discriminator 1, in the drive-distinguishability sense). Noise error sits exactly at the irreducible floor.
- **Phase 2 (non-stationarity) — the "value compounds only on a moving frontier" prediction, refined.** LP **exhausts on the stationary task** (the plateau — consistent with the falsifier) and **re-engages under drift**. But naive LP `−d‖e‖/dt` has a failure the doc didn't anticipate: as a **derivative it is blind to a *re-opened* frontier** (error *rising* reads as zero LP), so right after an abrupt change it diverts to **noise's sampling-jitter fake-LP** and lags/forgets — *worse than random*. **Continuous (gradual/`morph`) drift** largely fixes this (no big blind window); the residual blindness is partly fundamental to a derivative.
- **Phase 2b (scarcity + ensemble) — the fresh-FM prescription validated, with a nuance.** LP only *beats uniform* under **scarcity** (a small moving reducible frontier among many distractors — the "select harder targets among many" the doc assumes; an equal-thirds arena has none). There the **fresh-FM ensemble (cross-model disagreement)** reliably finds and tracks the needle — over-sampling it 3.7×→8.5× as it shrinks — because disagreement rejects the aleatoric noise field by construction and, being a **magnitude not a derivative**, has no re-opening detection lag. **Nuance (load-bearing for the theory):** naive LP is *not qualitatively broken* — with enough horizon it partially finds the needle and at maximal scarcity beats every drive except the ensemble — so **the ensemble is a consistent *quantitative* improvement, not a strict qualitative necessity.**

**Refinements this feeds back into the theory:** (1) the fresh-FM ensemble is needed *specifically under non-stationarity + scarcity* — Phase-1's stationary noisy-TV did *not* need it (LP's sustained signal dominated); (2) a **magnitude-of-reducible-disagreement** ("reducible surprise") may be a better drive than the LP *derivative* — it avoids the re-opening blindness while still rejecting noise, a candidate sharpening of "reward = `−d‖e‖/dt`"; (3) **gradual vs abrupt** non-stationarity matters — a derivative-based drive degrades gracefully under gradual drift and catastrophically under jumps.

**Still untested / deferred** (nothing here contradicts them): calibration-recovered-OOD (disc 2), two-roles-separable (disc 3), value-shapes-the-inner-loop (disc 4, needs a trainable operator), wireheading (no learned value yet), and the frozen-vs-plastic magnitude question.

## Predictions / falsification

- **Falsified if** a task-only (no intrinsic value) policy explores and calibrates just as well — i.e. the extrinsic task loss already *is* the value function. (Prediction: it collapses on the exploration-forcing geometry and stays uncalibrated OOD.)
- **Falsified if** learning-progress reward and raw-surprise reward behave identically on the noisy-TV control.
- **Falsified if** the value loop compounds *on a stationary task* — [RHM_META_LEARNING](../experiments/rhm/ratchet/RHM_META_LEARNING_README.md)/[RHM_SCULPT_CONTINUAL](../experiments/rhm/RHM_SCULPT_CONTINUAL_README.md) predict it saturates in one pass and only re-opens under a moving frontier (deeper level / fresh rules).
- **Confirmed strongly if** the value head recovers OOD calibration every FM probe missed, *and* the inner-loop forecast becomes value-shaped as a *consequence* of the outer loop.
- **Open magnitude question**: how frozen the value head should be — fully frozen (max robustness, may not fit) vs fully plastic (collapses into the inner loop) — the direct analog of Ilya's complexity-robustness tradeoff.

## Open questions

- Should the value head read the **state**, the **forecast** `p` (its value-relevant direction), or the **residual** `e` (reducible part)? The learning-progress reward wants `e`; the value-direction result wants `p`. Possibly both, at different sites.
- Is `−d‖e‖/dt` measurable stably enough online, or does it need the fresh-FM ensemble-invariance as a per-step proxy for reducibility (avoiding the noisy TV without a clean temporal derivative)?
- Does the frozen value prior act as the **implicit abstraction-lift regularizer** the FM-regularizer intuition predicted — now with a reward reference rather than pure legibility?
- Does the two-timescale split reproduce **wake/sleep** structure — inner loop = wake (fast, plastic), value consolidation = sleep (slow) — and does putting *reward* in the sleep loop change what distillation does (which [self_model_needs_a_loop](self_model_needs_a_loop.md) found was mostly re-derivation)?
- Language port: does a learning-progress value head over the a2a language loop develop **per-behavioral-category** value (the multi-task selectivity a2a next-step #1 wants)?
