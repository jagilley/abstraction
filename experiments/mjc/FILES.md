# MuJoCo control substrate — File & child index

Full file-by-file reference for the `mjc` node. Summarized in [README.md](README.md); this is the
lookup material. Per [STRUCTURE.md](../../STRUCTURE.md), **code lives at the lowest node that shares
it** — only genuinely shared machinery lives here; each child node's own scripts, figures and logs
live inside that child, indexed by its own `FILES.md`.

## Code files (shared — every child imports these)

| File | Purpose |
|---|---|
| `shared.py` | Modal infra: image (mujoco 3.2.3 + torch + matplotlib/scipy), `mujoco-control-data` volume, `mujoco-control` app, `NumpyEncoder`. Top-level imports kept to modal/json only; `mujoco`/`torch`/`matplotlib` imported inside function bodies so the app submits from a laptop without them. Ships the package via `.add_local_python_source("mjc")`, which recursively includes every child subpackage, plus **`.add_local_python_source("rhm")`** so [`expansion/`](expansion/README.md) can import the frontier instrument from `rhm.residual_decomposition.decomposition` rather than vendoring a copy that could drift from the instrument of record (pure numpy, empty package `__init__`s, no Modal app pulled in; no prior cut imports `rhm`). |
| `pusher_env.py` | Planar pusher DGP. `DEFAULT_DGP` knob dict; `build_xml(dgp)` (MJCF string builder — gravity-free 2D, pusher + puck + 4 walls); `PusherEnv` (reset, `set_state(qpos,qvel)` for perfect-simulator queries, `step(ctrl, n_sub)` with contact aggregation via `mj_contactForce`); `collect_transitions(...)` (scripted OU + seek-the-puck rollouts → `(S,U,S2)` + contact labels `force`/`puck_force`/`ncon`/`any_contact`/`puck_contact`; `theta=1` gives i.i.d. commands — this is the cut-#1/#2 *ancestor* of on-policy collection and is untouched); **`collect_pool(..., collection_mode=...)`** — the arm's mirror, new with the [`COLLECTION_REALISM.md`](on_policy/COLLECTION_REALISM.md) fix. `STATE_LABELS` = the 8 state-dim names. **Optional `puck_field`** (a deterministic nonlinear multi-mode force applied via `qfrc_applied` at runtime — `_field_force`/`_apply_fields`; on the puck and optionally the pusher via `pusher_amp`): the capacity-hungry-but-reducible value-irrelevant factor for [`value_shaping/`](value_shaping/README.md). Also **optional `field_patch`** (a Gaussian-gated multi-mode reducible force = the *drifting* frontier) and **`noise_patch`** (a Gaussian-gated stochastic/aleatoric force = the noisy-TV decoy) on the pusher, via `_apply_pusher_perturb`, for [`curiosity_control/`](curiosity_control/README.md); **`patch`** (a localized force jet) for [`directed_readapt/`](directed_readapt/README.md); and **`rot_regions`** (K spatially-localized, open-loop-compensable command→motion rotations) for [`ballistic/directed/`](ballistic/directed/README.md). **Every perturbation is additive and off by default — the XML is byte-identical when unused, so all prior cuts stay reproducible** (verified at 0.0 max difference). |
| `arm_env.py` | **Arm substrate DGP** (see [`arm_substrate/`](arm_substrate/README.md)). Planar N-link torque-driven arm: `DEFAULT_DGP`, `build_xml(dgp)` (MJCF from a knob dict — gravity-free planar chain, hinge axes +z, contacts off by default), `ArmEnv` (matches `PusherEnv`'s API: `get_state`/`reset`/`set_state`/`step`, plus `tip_pos`/`goal_pos`/`nonfinite`/`max_absq`), `fk(q, L, upto=k)` (analytic FK, verified against MuJoCo `site_xpos` to 2e-16), `collect_pool(..., collection_mode="teleport" | "on_policy")` — teleport by default and **bit-identical to the pre-flag implementation** (gated by `on_policy/verify_backcompat.py`); `on_policy` routes to [`embodied.py`](embodied.py), where `q_center`/`q_range` become the *episode-start* distribution and `v_explore` has no analogue. Perturbations, all additive & off by default: **`payload_mass`** (inertial, config-local), **`curl_field`** (velocity-dependent end-effector field via the exact `mj_jacSite` Jacobian = the Shadmehr force-field protocol; the best-measured quality axis and what aftereffects are defined on), `torque_rot` (the `push_rot` analog), `joint_noise` (aleatoric), and **`n_passive`/`tool_mass`/`tool_damping`/`goal_site`** (a passive tool = capacity competition from MORPHOLOGY; `goal_site` flips value-relevance with the physics byte-identical). `tool_damping` auto-scales to the explicit-integration stability limit `dt < 2I/c` — a light passive link otherwise NaNs silently. **`locked_joints`** (+ `lock_solref`/`lock_solimp`) pins named joints via an `equality/joint` constraint **and emits their motors with `gear="0"`** — degrees of freedom the body does not have *yet*, for [`expansion/`](expansion/README.md) Piece 3. It keeps the state 2n-dim and the command n-dim so one FM spans every body; the gear-zeroing is load-bearing because MuJoCo equality constraints are **soft** and a gear-8 motor drifts a pinned joint 0.16 rad per control step. Additive and off by default. |
| `embodied.py` | **Embodied (on-policy) collection — the `COLLECTION_REALISM.md` fix.** `Body` (B parallel episodes through one plant; one `MjData` *per episode*; every `env.step` charged against a budget; **`set_state` deliberately not exposed**, so teleporting is unrepresentable rather than discouraged), `collect_on_policy` (returns the transitions a body actually lived, with episode ids and within-episode timesteps attached), the behaviour rungs `OUBehaviour` (B1) and `ReachBehaviour` (B2/B3 — same class, frozen vs live FM), goal samplers (`sampler(states, rng)`, drawn *from the posture the body reset to*), and the per-mode diagnostics `cmd_state_corr` (Cut #2's identifiability instrument), `coverage_stats`, `pool_diagnostics`. |
| `render_video.py` | Rendered video: top-down MuJoCo view + live FM-residual side panel (headless OSMesa). Writes `videos/` and `figures/render_smoke.png`. |
| `__init__.py` | Package marker (empty). Each child folder has one too, so `.add_local_python_source("mjc")` ships the whole tree. |

**Why the package is `mjc` and not `mujoco`**: `.add_local_python_source` lands the package on Modal's
`sys.path`, so a local package named `mujoco` would shadow the real `mujoco` pip package that every
env module imports. The Modal volume (`mujoco-control-data`) and app (`mujoco-control`) deliberately
keep their original names, so all prior results stay addressable at the same `/data/...` paths.

The head learns the three-way split (**AUROC 0.857**, leave-one-region-out **0.882**); `d` is the best reward-free reducibility reader (**0.716**) and beats a privileged ceiling-based one; `e` is inverted (0.066) and `v` is 0.522/1.000 — relevance is not in the epistemic signature.
