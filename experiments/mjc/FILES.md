# MuJoCo control substrate — File & child index

Full file-by-file reference for the `mjc` node. Summarized in [README.md](README.md); this is the
lookup material. Per [STRUCTURE.md](../../STRUCTURE.md), **code lives at the lowest node that shares
it** — only genuinely shared machinery lives here; each child node's own scripts, figures and logs
live inside that child, indexed by its own `FILES.md`.

## Code files (shared — every child imports these)

| File | Purpose |
|---|---|
| `shared.py` | Modal infra: image (mujoco 3.2.3 + torch + matplotlib/scipy), `mujoco-control-data` volume, `mujoco-control` app, `NumpyEncoder`. Top-level imports kept to modal/json only; `mujoco`/`torch`/`matplotlib` imported inside function bodies so the app submits from a laptop without them. Ships the package via `.add_local_python_source("mjc")`, which recursively includes every child subpackage. |
| `pusher_env.py` | Planar pusher DGP. `DEFAULT_DGP` knob dict; `build_xml(dgp)` (MJCF string builder — gravity-free 2D, pusher + puck + 4 walls); `PusherEnv` (reset, `set_state(qpos,qvel)` for perfect-simulator queries, `step(ctrl, n_sub)` with contact aggregation via `mj_contactForce`); `collect_transitions(...)` (scripted OU + seek-the-puck rollouts → `(S,U,S2)` + contact labels `force`/`puck_force`/`ncon`/`any_contact`/`puck_contact`; `theta=1` gives i.i.d. commands — this is the cut-#1/#2 *ancestor* of on-policy collection and is untouched); **`collect_pool(..., collection_mode=...)`** — the arm's mirror, new with the [`COLLECTION_REALISM.md`](COLLECTION_REALISM.md) fix. `STATE_LABELS` = the 8 state-dim names. **Optional `puck_field`** (a deterministic nonlinear multi-mode force applied via `qfrc_applied` at runtime — `_field_force`/`_apply_fields`; on the puck and optionally the pusher via `pusher_amp`): the capacity-hungry-but-reducible value-irrelevant factor for [`value_shaping/`](value_shaping/README.md). Also **optional `field_patch`** (a Gaussian-gated multi-mode reducible force = the *drifting* frontier) and **`noise_patch`** (a Gaussian-gated stochastic/aleatoric force = the noisy-TV decoy) on the pusher, via `_apply_pusher_perturb`, for [`curiosity_control/`](curiosity_control/README.md); **`patch`** (a localized force jet) for [`directed_readapt/`](directed_readapt/README.md); and **`rot_regions`** (K spatially-localized, open-loop-compensable command→motion rotations) for [`ballistic/directed/`](ballistic/directed/README.md). **Every perturbation is additive and off by default — the XML is byte-identical when unused, so all prior cuts stay reproducible** (verified at 0.0 max difference). |
| `arm_env.py` | **Arm substrate DGP** (see [`arm_substrate/`](arm_substrate/README.md)). Planar N-link torque-driven arm: `DEFAULT_DGP`, `build_xml(dgp)` (MJCF from a knob dict — gravity-free planar chain, hinge axes +z, contacts off by default), `ArmEnv` (matches `PusherEnv`'s API: `get_state`/`reset`/`set_state`/`step`, plus `tip_pos`/`goal_pos`/`nonfinite`/`max_absq`), `fk(q, L, upto=k)` (analytic FK, verified against MuJoCo `site_xpos` to 2e-16), `collect_pool(..., collection_mode="teleport" | "on_policy")` — teleport by default and **bit-identical to the pre-flag implementation** (gated by `on_policy/verify_backcompat.py`); `on_policy` routes to [`embodied.py`](embodied.py), where `q_center`/`q_range` become the *episode-start* distribution and `v_explore` has no analogue. Perturbations, all additive & off by default: **`payload_mass`** (inertial, config-local), **`curl_field`** (velocity-dependent end-effector field via the exact `mj_jacSite` Jacobian = the Shadmehr force-field protocol; the best-measured quality axis and what aftereffects are defined on), `torque_rot` (the `push_rot` analog), `joint_noise` (aleatoric), and **`n_passive`/`tool_mass`/`tool_damping`/`goal_site`** (a passive tool = capacity competition from MORPHOLOGY; `goal_site` flips value-relevance with the physics byte-identical). `tool_damping` auto-scales to the explicit-integration stability limit `dt < 2I/c` — a light passive link otherwise NaNs silently. |
| `embodied.py` | **Embodied (on-policy) collection — the `COLLECTION_REALISM.md` fix.** `Body` (B parallel episodes through one plant; one `MjData` *per episode*; every `env.step` charged against a budget; **`set_state` deliberately not exposed**, so teleporting is unrepresentable rather than discouraged), `collect_on_policy` (returns the transitions a body actually lived, with episode ids and within-episode timesteps attached), the behaviour rungs `OUBehaviour` (B1) and `ReachBehaviour` (B2/B3 — same class, frozen vs live FM), goal samplers (`sampler(states, rng)`, drawn *from the posture the body reset to*), and the per-mode diagnostics `cmd_state_corr` (Cut #2's identifiability instrument), `coverage_stats`, `pool_diagnostics`. |
| `render_video.py` | Rendered video: top-down MuJoCo view + live FM-residual side panel (headless OSMesa). Writes `videos/` and `figures/render_smoke.png`. |
| `__init__.py` | Package marker (empty). Each child folder has one too, so `.add_local_python_source("mjc")` ships the whole tree. |

**Why the package is `mjc` and not `mujoco`**: `.add_local_python_source` lands the package on Modal's
`sys.path`, so a local package named `mujoco` would shadow the real `mujoco` pip package that every
env module imports. The Modal volume (`mujoco-control-data`) and app (`mujoco-control`) deliberately
keep their original names, so all prior results stay addressable at the same `/data/...` paths.

## Children (each is a node with its own `README.md` + `FILES.md`)

| Child | Summary |
|---|---|
| [`contact_residual/`](contact_residual/README.md) · [files](contact_residual/FILES.md) | **Cut #1 — contact-residual structure.** An arity-2 FM's residual concentrates **8.1×** at contact (AUC 0.86) and is *directionally* worse there (cosine 0.99 free / 0.82 contact — a scale-free control), scales with contact force (ρ=0.75), and is velocity-localized. The sharpened claim: an onset-aligned event-triggered average shows the residual **spikes at the impact transition and decays while contact persists** — an *event* detector, not a *state* detector, confirmed by the no-spike separation-aligned control. Gotcha: **Huber, not MSE**. |
| [`arity_torque/`](arity_torque/README.md) · [files](arity_torque/FILES.md) | **Cut #2 — arity on torque.** Under i.i.d. commands (max \|corr(u,s)\|=0.003, killing the generator confound), **arity beats resolution**: arity-2 pusher-velocity R²≈0.999 at every capacity, arity-1 flat at ~0 across 8→256 hidden. The gap is localized on the directly-actuated dims; the interventional readout (vary `u` at a fixed state in the perfect sim) makes observational→interventional physical. |
| [`dynamics_shift/`](dynamics_shift/README.md) · [files](dynamics_shift/FILES.md) | **Cut #3 — operator intervention: reward-free re-adaptation.** Intervene on the transition operator with the task held fixed; the shift corrupts only the world-model factor, so MB recovers to the oracle ceiling from **~50 reward-free transitions** while a protocol-matched committing motor-program MF is flat and needs ~240× more reward-labeled data. Gated by re-groundability (`replan_every` ablation), peaking at the FM's ~6–8-step composition horizon. **The substrate most later nodes build on.** |
| [`value_shaping/`](value_shaping/README.md) · [files](value_shaping/FILES.md) | **Value-shaping as capacity re-allocation** (the value→FM interface, learning-layer, **stationary**): robust per-dim re-allocation away from a reducible-but-value-irrelevant nonlinear puck field, with an irreducible contact-impulse foil; the "teeth" (capacity efficiency) are a fragile data-scarcity effect. The stationary *control* for every non-stationary meta experiment below. |
| [`directed_readapt/`](directed_readapt/README.md) · [files](directed_readapt/FILES.md) | **Directed reward-free re-adaptation — two instructive negatives.** A global shift gives no scarcity (null); a localized force-jet patch has scarcity but the **disagreement drive is blind to a confident-prior shift** (under-visits the patch, 3 seeds). Composes into "the drive needs scarcity **and** a signal that flags confident-wrong regions" + the drive-ranking-by-regime flip. Motivates the pivot to phenomenon-first work. |
| [`meta_adapt/`](meta_adapt/README.md) · [files](meta_adapt/FILES.md) | **Cut #4 → #4e — phenomenon-first meta-learning, the whole FM↔value interchange arc.** #4: the 1-D damping **floor collapses** (meta−multitask gap ≈ 0, the RHM anchor), the **actuator-rotation conflict opens the gap monotonically with Φ** (~8× at Φ=π/2, textbook MAML crossover). #4b: a context latent `z` **decodes the task parameter** (system-ID R²≈1.0) — and system-ID ⊥ adaptation-benefit. #4c: VoI-directed identification is a **robust scarcity-gated negative**. #4d: value-shaping × meta-conditioning are **separable capacity levers**; the re-allocation is value-*caused*, veridicality⊥usefulness, and buys control only under capacity competition (+0.036±0.012 at h=64, 4 seeds). #4e: **disc-4 closed** — a reward-driven outer loop both prefers the puck-drop and rediscovers V's support (3 seeds), plus the wireheading / normalize-the-budget gotcha. |
| [`curiosity_control/`](curiosity_control/README.md) · [files](curiosity_control/FILES.md) | **Curiosity on control — the afferent explore drive + grounding.** An intrinsic reducible-surprise drive directs **where to collect** as a scarce reducible frontier **drifts**: it tracks the moving frontier and sustains control (a specifically *non-stationary* effect — it ties when static), with a **value-relevance dissociation** (tracks off-path, pays only on-path). Pure curiosity has a **noisy-TV pathology on low-dim control** (disagreement chases aleatoric noise — inverting the active-vision result); **grounding with the exploit signal as two additive drives cures it**, with an intermediate-balance optimum = the `e`-tap + `p`-tap as one system. |
| [`online_value_loop/`](online_value_loop/README.md) · [files](online_value_loop/FILES.md) | **The fully-online two-timescale value loop — obstructed on both levers, which *confirms* the premise.** Built the keystone (reward continuously shaping a *live* FM) afferently (`meta_curiosity_loop.py`) and efferently (`meta_value_online.py`). Both fast-online discoveries are obstructed: CEM-MPC control is robust to the drive's tracking effect; the value-shaping benefit is a long-horizon, commit-dependent, pre-convergence transient. Net: **value is a slow/committed/offline-estimable quantity — the two-timescale split is *forced*** — and its benefit is **adaptation speed**, not converged competence. |
| [`drift_value_loop/`](drift_value_loop/README.md) · [files](drift_value_loop/FILES.md) | **The two-timescale value loop under perpetual drift — the three-cut arc.** (1) Compounding is real but comes from the ***memory***, not the value-carving (a context-latent `f(s,u,z)` compounds across a `push_rot` drift sequence; pooled monolithic memory is a *liability* under conflict). (2) Value-relevance carving is capacity-gated & control-robust (the blind grader). (3) **The corrected teacher**: grade the meta-loop by the value-relevant FM prediction-error (cerebellum→VTA), not control → the explore/exploit balance `b` has a clean interior optimum at 0.5 where control is flat. **Net: the missing piece was the *teacher*, not the value *structure*.** |
| [`ballistic/`](ballistic/README.md) · [files](ballistic/FILES.md) | **Ballistic control — when the forward model becomes behaviorally load-bearing (the efferent bridge).** The FM→behavior bridge doesn't transmit under CEM-MPC because **replanning is a blind grader**; this resolves it as a fact about the **control mode**. A ballistic (feedforward, open-loop) controller makes the FM ~3× more load-bearing than reactive (damping-staleness, 3 seeds), and online reward-free FM re-adaptation restores ballistic competence ~4.3× more than reactive after a drift (3 seeds). Lead reading: the cerebellar FM is the reward-free-maintainable *and* the feedforward-critical asset — the same object. Has its own child, [`directed/`](ballistic/directed/README.md), which lands the directed-collection ladder (a reward-free `learning-progress × visitation` signal recovers the oracle allocation). |
| [`arm_substrate/`](arm_substrate/README.md) · [files](arm_substrate/FILES.md) | **The planar arm substrate — a second task family, and capacity competition that comes from the body** (the DGP `arm_env.py` stays at this node as shared machinery; `arm_probe.py` is the characterization). Verified: capacity binds intrinsically **only at n≥5** ("nonlinear" and "capacity-hungry" are separate axes); ballistic transmits FM quality **6.0×** more than reactive; composition horizon **14–23 steps** (pusher ~6–8); a **passive tool** spans #4d's capacity-competition boundary with one knob in **kg**, and `goal_site` flips value-relevance with the physics byte-identical. Three transferable gotchas: grade FM error on the **task** distribution; **size the open-loop CEM to the action-sequence dimension**; a light passive link NaNs *silently* past the explicit-integration stability limit. Characterization only — no cut ported yet, single seed. |
| [`on_policy/`](on_policy/FILES.md) | **Embodied collection — building and pricing the [`COLLECTION_REALISM.md`](COLLECTION_REALISM.md) fix.** The `collection_mode` flag's own node: the backwards-compatibility gate (`verify_backcompat.py` — the teleport path is bit-identical, checked, not promised) and **E0** (`coverage_probe.py`), which runs the B0–B3 behaviour ladder at matched environment-step budgets to measure what on-policy acquisition costs before a cut is spent on it. Characterization, not a cut. *Running; README pending results.* |
