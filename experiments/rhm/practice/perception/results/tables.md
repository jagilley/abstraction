## T0 — what the series are, and how to reproduce every number

The practice arc's yield thermostat reads `at_support`: distinct level-(active+1) tuples seen at least `mine_support` times over the learner's own solved trajectories. RHM hands that miner a GRID -- the solved piece is a whole aligned sequence, so `(era.level, era.node)` names which span of it to read. Here the grid is instead recovered from a next-token reader's own entropy period (`logit_reading/frontier/common.py::nested_phase`, template-free `meanprof` mode) on windows in which each mined piece sits at an offset the reader is not told.

| series | keying | grid | what it is |
|---|---|---|---|
| **A** | level-1 features | true | the run's own `obs_hist` -- what the thermostat actually read |
| **Bf** | level-1 features | true | A recomputed on this window set (identity check) |
| **Cf** | level-1 features | recovered | **the endogenous gauge** |
| **Df** | level-1 features | shuffled offset | a wrong grid at the right period |
| **B / C / D** | leaf tokens | true / recovered / shuffled | the same three in leaf-token keying, on streams padded with the cycle's other solved beam tips |

```bash
cd experiments            # MODAL_PROFILE=chromatic
# the whole node, two waves across containers (~1.8 GPU-h, ~58 min wall)
modal run --detach -m rhm.practice.perception.sweep::sweep --tag pc0
# the feature-keyed panels (mined-only streams, the thermostat's own coordinates)
modal run -m rhm.practice.perception.evaluate::evaluate --tag pc0 --arm corpus \
    --stream-from mine --out-name panel_corpus_feat
modal run -m rhm.practice.perception.evaluate::evaluate --tag pc0 --arm own \
    --stream-from mine --out-name panel_own_feat
# tables and figures (local, CPU)
python3 -m rhm.practice.perception.analyze --tag pc0 --fetch --figs
```
