==========================================================================================

      `reh_level`. Every arm that does not set it must reproduce `as_s0`'s arm of
      the same name bit-for-bit over all 116 cycles. That IS the knobs-off gate.
      anchor       not in this tag — skipped
      exact        max|delta| over 13 series = 0.000e+00   cycle counts equal = True   -> PASS

  (b) IN-TAG TWIN GATE. `exact_reh` / `exact_exp` are `exact` plus rehearsal, and
      rehearsal cannot fire before the rehearsed level arrives. Up to that cycle
      all three must be identical; at it they may diverge and not before.
      exact_reh    first rehearsal cycle = 71   pre-window c1-c70: max|delta| = 0.000e+00 -> PASS   first divergence from `exact` = c71
      exact_exp    first rehearsal cycle = 71   pre-window c1-c70: max|delta| = 0.000e+00 -> PASS   first divergence from `exact` = c71

  (c) THE ONE-BIT PAIR. `exact_reh` and `exact_exp` run the same episodes and take
      the same number of gradient steps on the same-size pair sets; they differ in
      whether the success filter picks which trajectories pi imitates.
      rehearsal cycles: 46 vs 46
      first rehearsal cycle pair-count match (the assertable one): used 1264 vs 1264  -> PASS
      later cycles differing in pairs-used: 44/45 (expected once the arms diverge; NOT a gate)
      NOTE: `n_pairs_all` is structurally constant (train_on='tips' keeps every surviving trajectory), so matching it is vacuous and is not a gate.

  (d) THE UNREHEARSED LEVEL is this round's only in-tag noise handle. Rehearsal
      targets L3 only, so whatever spread the three `exact` arms show at L2 is what
      trajectory divergence alone produces in this instrument. Quantified at the end
      of section (2). It is not a measured floor (single seed, n=3) but it is the
      only same-tag reference the round contains.
