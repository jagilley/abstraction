# full_loop — File index

Complete file-by-file reference for this sub-experiment. Summarized in [README.md](README.md).

Primitives live two levels up at [`../../`](../../FILES.md) because they are shared across RHM experiments
(per [`STRUCTURE.md`](../../../../STRUCTURE.md) — code lives at the lowest node that shares it):
[`../../rhm_channels.py`](../../rhm_channels.py) (the distractor DGP),
[`../../rhm_drift.py`](../../rhm_drift.py) (support-fixed drift, per-event σ calibration, the stationary
anchor), [`../../rhm_repair_cost.py`](../../rhm_repair_cost.py) (the meter and the homeostatic readout).
The sculpting apparatus this extends is [`../../rhm_sculpt_latent.py`](../../rhm_sculpt_latent.py) and
[`../../rhm_sculpt_internalize.py`](../../rhm_sculpt_internalize.py).

## Code files

| File | Purpose |
|---|---|
| `channel_env.py` | The multi-channel sculpting **environment** — what turns the DGP into a control task. Per-block rendering tables (each channel edits through its own grammar; noise blocks redraw iid), mixture rendering so drift changes the edit *dynamics* rather than only the data distribution, tree-only corruption, channel-aware generator/value/FM trainers, the three FM taps (`counterfactual_lp` = explore, `forecast_visits` = relevance, the two beams = control), depth/PR probes on the tree slice, the allocation policies, world snapshot/restore for cross-world grading, and Stage-5's belief-internalization ladder ported onto the layout |
| `env_check.py` | **E1–E6** certifying that environment before the loop runs on it: edit determinism under `canon`, the per-channel **irreducible floor** measured by redrawing the same `(x,k)`, FM learnability against that floor, DP solvability, the ballistic **commit-length** sweep that sets `chunk_len=3`, and the learned value's ΔV per channel against the exact DP Δ`d*`. Also `fm_bisect`: reference → tree-only → full-canon → full-mixture, one variable at a time — the back-compat gate for the port |
| `ladder.py` | **E1** — E3's allocation ladder over channels under continuous drift, ten policies. Carries the `e` tap in **two estimators run side by side** so the estimator itself is a controlled variable: the counterfactual fit (`lprog_only`/`value`/`value_satiety`) and floor-corrected reducibility (`reducible_only`/`value_red`/`value_red_satiety`). Both are computed every round for every arm, so the monitor charge is identical and only the allocation rule differs. Graded by tree-channel FM error (sighted) and ballistic beam success (behavioural), with the reactive beam as the near-blind control. Also carries `PricedMeter` + `mon_price`/`meter_budget` for [`metering_sweep/`](metering_sweep/README.md); at `mon_price=1.0` the charge takes the original `int(n)` path, so every prior run reproduces bit-identically |
| `climb.py` | **E2** — repeated drift events with a *trainable* belief, against a `nodrift` matched-compute arm, on per-event σ matching and the entropy-matched control. Two sweeps: **which level drifts** (`surface`/`mid`/`root`) and — the one that produced the positive — **samples per event** at fixed KL/event, each budget carrying its own matched control. Reads repair-per-event against the per-level depth probe |
| `expansion.py` | **E3** — the grader-type × drift 2×2 (`frozen`/`dense`/`evaluative` × `static`/`drift`), nested so `evaluative − dense` isolates grounding. Reads the belief's PR and depth *trajectory*, plus fresh-FM transferability and ballistic control graded in three worlds (`base` / `novel` / `own`). **Read its PR column against [`endo_expansion/`](endo_expansion/README.md) §3's content control** — a zero-information target reaches 145% of the DP teacher's PR lift with control at the no-loop floor |

## Children

| Child | What |
|---|---|
| [`endogenous_expansion/`](endogenous_expansion/README.md) | **Can an endogenous evaluative grader expand?** The cell neither §3 nor §5 ran: `visits` is endogenous but was only tested for allocation, and the DP `k*` teacher expands but is external. Seven arms differing in one variable — where `belief_update`'s target comes from — with the published static rows reproduced in-run. Answer: yes, at 19% of the teacher's ballistic lift, and two fidelity-matched external controls show the gap is **fidelity, not endogeneity**. Also retires belief PR as a *ranker* (it anti-correlates with target quality, ρ = −0.80) and finds no dimension-count replaces it, `R_res_participation` included |
| [`endo_expansion/`](endo_expansion/README.md) ([FILES](endo_expansion/FILES.md)) | **E4 — the endogenous-expansion cut**, the central gap named in [`ideas/meta_learning_under_metered_data.md`](../../../../ideas/meta_learning_under_metered_data.md)'s own "What this does not establish": §5's teacher expands but is external, §3's `visits` is endogenous but only ever allocated, and no run was both. Nine arms on one warm start, pre-registered. A Monte-Carlo teacher reading only the environment's terminal reward recovers 34% of the DP teacher's ballistic lift and 53% of its transferable plannability, with grader-disagreement on the *external* teacher's side of the homogeneous floor — so the loops did not collapse. Carries the first quantitative homogeneous-vs-heterogeneous disagreement measurement in the repo ([`heterogeneous_graders.md`](../../../../ideas/heterogeneous_graders.md) §9's load-bearing test, first half), the endogenous-allocation cut (sculpt-continual's next step #3), a scoped negative on §7's paid-vs-reported design rule, and **the content control that shows belief PR is anti-informative about expansion on this substrate** |
| [`metering_sweep/`](metering_sweep/README.md) | **The metering test** — the idea doc's own load-bearing test, never run because the meter had never been a variable (every ladder reports 1.78125×). Needed a design change first: the `Meter` is **inert** (nothing reads it, so a bare price multiplier is a no-op) and `uniform`/`oracle` are **tap-blind** (so the prize responds only to the collection monitoring displaces). 87 runs, two pre-registered rounds, seven limbs: price at fixed total spend, an abundance limb to B=262144, an information control, a damage sweep, data-vs-compute, the **honest ladder** (each arm buys its own taps), and **iso-compute** curves. Carries three things back to this node: `fm_epochs=8` is demonstrably over-trained — the ten-arm ladder re-run at 1/2/4 epochs is 0.03–0.07 better per arm with the prize 17% lower, though **every published contrast and the ordering survive**; at matched compute the uniform→oracle prize **turns over** at the abundant end; and once a tap is *priced*, relevance keeps 87% of the oracle prize for 2.2% of the budget while reducibility is worth nothing at all |
| [`level_moves/`](level_moves/README.md) | **A level-indexed action space** — a move that commits to one level-ℓ feature and renders the legal subtree beneath it, reducing exactly to `regenerate_block` at ℓ=1. Answers what the value thinks a level of the hierarchy is worth: the DP says depth raises the floor not the ceiling (random-move Δ`d*` 6.7× from L1 to L4, best-move nearly flat), ~~and the value's per-node preference climbs monotonically to 5.0× against the oracle's 8.2×~~. **Corrected 2026-08-03 in the same node (its §9–§12)**: the **span null**, extended to a *depth-matched* distractor, accounts for the whole level profile (null |ΔV| rises 2.79× L1→L4 against the tree's 2.56×), and the per-node headline is one seed of three. Two structural replacements, both reusable: a **matched-span paired control** (`--lazy-twins`, each committed move against a *lazy twin* rewriting identical tokens without committing — the value prefers the commitment, 0.557 ± 0.018 at L2 / 0.618 ± 0.052 at L3 against the oracle's 0.610 / 0.642, and only 4.4% of the premium survives where legality buys Δ`d*` = 0, so it is task-referenced not grammatical); and **hierarchical damage** (`--damage-level`, a level-k subtree swapped for a legal derivation of a feature `possible_sets` proves it cannot produce — 100% on-grammar at matched `d*`, against published damage that is off-grammar in 29% of tree blocks), under which the abstraction premium is graded by whether a commitment at that level can reach the error (L2 slope −0.033, t = −6.81) and value–oracle rank agreement doubles (+0.290 → +0.583). Also establishes that the **root cell is structurally unreadable** — a level-4 move masks every tree token, so its Δ`d*` premium is bit-identical across damage levels. Action space, damage model and readouts only; no FM, planner or allocator. **Child [`level_moves/level_ladder/`](level_moves/level_ladder/README.md) (2026-08-04)** adds the allocation half — span FM, (channel, level) budget, level-indexed planner/ballistic grader, deepening damage schedule — and finds the level index **inert as an allocation axis** (+0.00016 ± 0.00226, t = +0.13) and **3.51× as an action axis** |
| [`composed_loop/`](composed_loop/README.md) ([FILES](composed_loop/FILES.md)) | **The composed loop** — [`endo_expansion/`](endo_expansion/README.md)'s endogenous MC judge on [`level_moves/`](level_moves/README.md)'s level-indexed action space under hierarchical damage, which had never been in one run. Carries `belief_update_moves` (the plan term stacked over *moves* through the span FM, reducing to the published block term at `max_level=1`) and a block-matched dense-term move draw so the two action spaces see an identical channel mix. **Single seed throughout.** The 2×2 gives a large negative interaction — the endogenous judge's level gain (+0.189) equals the no-loop arm's (+0.186) against an external teacher's +0.453 — and two findings survive their own controls: the judge's **target level is flat at ~1.72 while an oracle climbs 2.23 → 2.80**, and **sharpening it does not move it** (a 1.5× sampling budget buys accuracy, 2.65× → 3.16× chance, and 0.06 of altitude); and **what the value's training rollouts explore is worth 45% of a privileged teacher** on the no-teacher arm (ballistic 0.316 → 0.479, under a bit-identical-controller comparison). An external ~14-bit level-floor instruction moves the target level 1.72 → 2.47, but its **reversed-schedule control does as well or better**, so the curriculum reading is refuted and only a post-hoc pattern survives |
| [`partial_hetero/`](partial_hetero/README.md) | **Cut-3, the partially-heterogeneous DGP** — the middle of the shared-structure axis that §5/§9 of [`ideas/meta_learning_under_metered_data.md`](../../../../ideas/meta_learning_under_metered_data.md) names as the missing realism condition. `structA` is depth-matched to the tree and takes its top *k* rule tables from it, so sharing depth is a knob running from full_loop's independent-grammar geometry (*k*=0) to specialization's single-ruleset geometry (*k*=4), with superficially-unrelated-but-deeply-shared in between. Two measurements: a static, coverage-matched **transfer curve** (what is off-channel data worth?) and **the ladder re-run at each sharing depth**, plus a transfer-aware `oracle_shared` rung that measures the gap between *stipulated* relevance and *actual* data value |
