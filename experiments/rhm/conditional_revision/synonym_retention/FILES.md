## Code files

| file | purpose |
|---|---|
| `synonym_retention.py` | **Retention vs distance** — does the state still carry which synonym realised a constituent that has already *closed*, as a function of how long ago it closed? Supplies the axis `local_loss`'s `_swap_sensitivity` lacks: that instrument perturbs the last level-(L−2) constituent and reads at the last position, so the perturbed span *contains* the read position and NTP constrains that state not at all — its `syn/str` is a retention readout at **zero retention distance**. Here a constituent `(level d, node j)` closing at leaf `e` is perturbed and the state is read at `t = e + w`, sweeping `w`. Four matched arms, all confined to the constituent's span with a bit-identical prefix before it: `leaf` (bump every leaf-emitting rule choice inside the span — no latent feature moves; this is the incumbent's "synonym"), `top` (bump the constituent's own rule choice — its feature is unchanged, every descendant feature is re-realised), `str` = `leaf` + `top` (the incumbent's "structure"), plus `rand` (off-DGP) and `other` (independent-sequence spread normaliser). **The perturbation is frozen across the `w` sweep** — the same bytes change at every `w ≥ 0`, so only read distance varies. `(d = L−2, j = s^(L−2)−1, w = 0)` reproduces the incumbent cell exactly. Two readouts: *causal* (‖h[e+w] − h_base[e+w]‖ per arm, normalised by the independent-sequence spread) and *probe* (decode the constituent's rule choice and its feature from `h[e+w]` against an **exact Bayes ceiling** from `oracle.prefix_beliefs` — `nodes[d]` for the feature, `cliques[d]` summed over the parent value for the rule — so retention is `(acc − chance)/(bayes − chance)`, pinned at both ends). The NTP floor is **measured, not assumed**: `generate_rules_distinct` draws each feature's `m` tuples independently across features, so distinct features can emit the same tuple and a closed span's realisation is *not* exactly redundant for the future (`aleatoric_fraction`'s `dgp_synonym_swap` already recorded `frac_TV_exactly_zero` of only 0.53–0.87). Every arm therefore carries its exact next-token TV at the read position, and every readout is reported both pooled and restricted to the provable `TV == 0` cells. `sweep_arms` runs the same readout across the `local_loss` checkpoints (λ=0 anchor, `tll_*`, `fmreg_*`), importing `_label_dir` from that module so the arm→directory map cannot drift. Forward passes only on cached checkpoints; nothing is trained. Runnable directly for the DGP-only self-checks with no Modal and no model. |
| `aggregate.py` | Reads the result JSONs and prints the tables — the per-level retention curves (probe accuracy, label-shuffled control, exact Bayes ceiling, normalised retention, per-arm relative displacement, exact next-token TV and the `TV == 0`-restricted displacement) and the arm comparison. The arm table joins each `local_loss` label against the FM-free activation rank published in `/data/rhm_temporal_local_loss/parts_ll1/` so the comparison is at **matched achieved compression**, not matched λ. Local, CPU, no Modal. |
