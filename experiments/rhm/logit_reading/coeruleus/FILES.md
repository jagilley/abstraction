# Files — logit_reading/coeruleus

**Up**: [README.md](README.md) · **Parent**: [../FILES.md](../FILES.md)

Every module imports the parent's `flat_oracle`, `calibration`, `phasic` and the sibling
[`altitude/`](../altitude/FILES.md)'s `dual_ladder` and `train_noisy` unchanged.

## Code files

| file | purpose |
|---|---|
| `events.py` | Shared machinery: the ε-corrupted held-out windows rebuilt bit-for-bit from `altitude/dual_ladder.make_windows`'s RNG *with* the corruption mask the cache does not store (`assert_cache_matches`); `events_from_mask` (isolated corrupted tokens with a clean ±H neighbourhood); the two one-knob consumers on frozen logits — a temperature `softmax(αz)` and a uniform noise floor `(1−w)q + w/v` — both convex and optimised exactly by bisection, pooled or per row. |
| `prize.py` | **Q1.** Per-offset excess of the model over the ε-observer at its own `κ*` (the family ceiling) and over truth, on the corrupted windows; what a temperature and a floor recover pooled, per offset, per event and per prediction; the diagnostic mixing weight toward every observer `k`. Modal `prize_ckpt` / `prize_sweep`. |
| `readout.py` | **Q2.** The self-supervised excess-surprise head: target `Σ_{u=t}^{t+8}(NLL_u − H(q_u))`, no labels; the exact minimum-MSE linear head from a streamed Gram matrix over every block and ridge penalty, an MLP beside it; contrasts on the raw future NLL and on `H(q)` alone; random-trunk and input-embedding floors; readouts for event detection, the calibrated-hard vs overconfident-wrong contrast, the per-offset profile, and the `swap65k` same-prefix pairs with the oracle-label probe on the same states. Modal `readout_ckpt`. |
| `gainloop.py` | **Q3.** Per-position gate → monotone temperature map (18-bin quantile step function with refined tails, each bin's `α` the exact NLL minimiser on held-out corrupted windows at `t ≥ 8`; a log-linear fit beside it); arms `const`, `head` (ridge / MLP), `oracle_probe`, `oracle_offset`; evaluated on the cached ladder windows so Q1's ceiling applies, plus the parent's 2e sign on the same-prefix pairs. Modal `gain_ckpt`. |
| `plasticity.py` | **Q4.** Continued training on the corrupted stream from a mid-trajectory checkpoint with the per-position NTP loss weighted by rank-normalised gates: `uniform`, `head_down`, `head_shuf`, `oracle_down`, `oracle_up`; the gate reads the live model through the frozen head and logs its correlation with the realised horizon excess. Modal `train_arm` / `plasticity_sweep`. |
| `analyze.py` | Local reduction over the JSONs pulled off the volume: every table in [`results/tables.md`](results/tables.md) and the figures in `figs/`. Reads only JSON — no Modal, no GPU. |
