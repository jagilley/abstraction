# Files — logit_reading

**Up**: [README.md](README.md) · **Parent**: [../FILES.md](../FILES.md)

## Code files

| file | purpose |
|---|---|
| `flat_oracle.py` | **The instrument.** Exact phase-marginal Bayes predictive for FLAT windows (what a model trained on random-offset windows is actually fit to), for the whole coarse-observer family: observer `k` knows the bottom `k` grammar levels and models the stream as i.i.d. depth-`k` subtrees with a position-averaged root prior, marginalising the unknown phase. Batched torch sum-product BP on the hypertree, optional Dirichlet synonym weights (`rule_w`) and optional per-token corruption (`noise_eps`, the observer that stays defined after a violation). `leaf_levels`, `sample_flat_windows`, `level_marginals`. `_self_test` (local, CPU) checks every observer against full enumeration — uniform 2.2e-16, weighted 2.8e-16, noisy 4.4e-16 — and against `conditional_revision/oracle.py` on the real grammar (1.1e-16). **Keep the brute-force test.** |
| `grammar.py` | Weighted-synonym RHM: `synonym_weights` (Dirichlet(alpha) per (level, feature)), vectorised `generate` with latents, and `realise` (regrow a subtree under a given feature). Rule tables are the usual `generate_rules_distinct` draw, so grammaticality is unchanged and only frequencies move; `rule_w=None` is the canonical uniform RHM. |
| `calibration.py` | **Part 1.** `summarize` (every statistic from arrays: `H(p)`, `H(q)`, `CE`, `KL(p_k‖q)` for all k, best-fit observer, phase-known reference, top-1 reliability, the two tower-property self-checks), `evaluate`, and three Modal entry points: `calibration` (the cached `conditional_revision` base), `calibration_ckpt` (one trajectory checkpoint), `calibration_sweep` (all of them, ≤ 4 GPUs). Also owns the shared Modal `app` and `load_trajectory_ckpt`. |
| `train_trajectory.py` | The checkpointed base trajectory: same architecture/optimiser/objective as the cached base, with Dirichlet(1) synonym weights and fresh data every pass (a learning curve, not a memorisation curve). 13 checkpoints to 64k steps, ~40 min on an L4. |
| `stimuli.py` | **Part 2 stimuli**, model-independent and built once per grammar. `make_edits` (swap / rare-synonym / none edits of one constituent at a chosen span and window index) plus the oracle labelling: `t_v` (first exactly-impossible token) and `k_star` (smallest observer that excludes it). Asserts legal streams never hit probability 0, nested supports, `t_v ≥ e`, `k* ≥ j+1`. `swap_only` / `with_reference` flags build the larger phasic-test set without the reference observers. |
| `violation.py` | **Part 2 readouts against controls from other windows.** `readouts_v2` is current: exact (token, level, window index) cells + nearest-neighbour surprisal matching, tonic-vs-phasic split (state at `t−1`, at `t`, and both), the model's own running surprisal, per-`k*` tables, transfer across `k*`, and `eps`-noise-referenced output persistence. `readouts` (v1) is kept for its recorded numbers only — **its guards failed** (8 quantile surprisal bins leak in the tail, 16-wide position buckets leak position; see README gotchas). Helpers `auc`, `fit_probe`, `nn_match`, `match_strata`. |
| `phasic.py` | **The two follow-up controls.** `phasic_readouts`: same-prefix twins — the violating token replaced by a legal one at matched model surprisal — so the context, and hence the tonic signal, is identical within a pair (asserted). `legal_gradient_readouts`: two *legal* tokens after the same prefix differing ≥ 2× in true probability, the graded control that shows the signal is likelihood-sensitivity rather than categorical legality. `balance_tokens` (greedy cycle extraction over the violator→twin multigraph) and `balance_ds_sign` pin the token-identity and paired-surprisal guards at 0.50. |
| `analyze.py` | Local aggregation over a trajectory's per-checkpoint JSONs: Part 1 table, detection-by-`k*`, the matched tables (v1 and v2), the phasic table and the graded control. Reads only JSON — no Modal, no GPU. |
