Every module imports the parent's `calibration`, `violation`, `phasic` and the sibling
[`coeruleus/`](../coeruleus/FILES.md)'s `events` (the corrupted-window reconstruction, the
cached ladder, `convex_obs`/`fit_kappa_pooled`, `mix_opt`/`mix_ce`) and `readout`
(`load_head`, `prefix_pairs`) unchanged. Nothing here retrains anything: the two checkpoints,
the `swap65k` stimuli, the cached observer ladders and the banked excess-surprise heads are all
read off the volume.

## Code files

| file | purpose |
|---|---|
| `hold.py` | **The instrument.** The hold-and-discount forecast in the model's own terms: re-run the model with the flagged position overwritten by each of the `v = 16` vocabulary tokens (`impute_logq`, exact marginalisation at this vocabulary size) and mix the passes four ways — `argmax`, `topK`, `full` (the exact prior marginal) and `pf`, a particle filter whose weights the continuation updates, causal at every offset (`prep_imputed`, `hold_forecast`). `log_bayes_factor` reads the model's own log odds between "that token was a glitch" and "that token was real" off the same passes, with no free parameter but the prior odds. The consumer is `q_w = (1-w) q_native + w q_hold`; `-log q_w(x)` is convex in `w`, so `w_opt` is exact by bisection and `fit_wmap` gives a quantile step function whose every bin is that exact minimiser (`coeruleus/gainloop.py`'s shape, fitted on realised NLL with no oracle in it). Also `logq_full`, `gather_offsets`, `states_offsets`. |
| `worlds.py` | **The stimulus construction.** `build_arms` cuts three populations out of the one `swap65k` draw so that the two worlds are the same stream at the same position and differ only in the continuation: `edit` (the edited window flagged at `t_v`), `glitch_m` (the *unedited* window with the token at the same `t_v` replaced by a uniform draw), and `quiet` (disjoint unedited windows flagged at a random position — the cost of a false alarm). `arbitrate.py` adds `glitch_s` on top, the same construction with the corrupting token chosen to match the edit's violator in model surprisal, which the model's own prefix forecast supplies. `natural_glitch_arm` is the other venue: `coeruleus/events.py`'s isolated corruptions on the cached ε-windows, where the exact ladder is on file. **`j = 0` swaps are one-leaf substitutions — glitches drawn from the grammar's own alphabet — so every edit readout is also reported split at `j >= 1`.** |
| `arbitrate.py` | **The run.** One Modal function per checkpoint (`arbitrate_ckpt`), fanned out one-per-container by `arbitrate_sweep`. Q1 the imputation variants; Q2 the per-world per-offset oracle `w`, each fixed policy's cost in the other world, the `delta`-lookback bound on where the culprit is, the ε-venue prize against **both** references (the window-observer's `p_L^eps` ceiling and the clean truth on the uncorrupted draw of the same windows), the parent's 2e entropy sign and the persistence profile under each policy; Q3 the mixed world at stated rates with the full rate grid; Q4 the gates — the banked excess head, a supervised world probe on the state with embedding and random-trunk floors, the model's entropy, the running excess since the event, the log Bayes factor, the flagged token's own surprisal, and beside every learned gate a shuffled gate and the exact label. Carries two exact self-checks: the imputed forecast must be bit-identical between a violator and its same-prefix legal twin, and the reconstructed ε-windows must match the cached ladder. |
| `gates2.py` | **The addendum (2026-09-17)**, on the gate / arbitration side only: the same populations, seed and 60/40 split as `arbitrate.py` (asserted against the main JSON's per-arm event surprisals), rebuilt so the first round's artifact is untouched. Four things the main round could not separate: every table recomputed on `j >= 2` **structural** edits beside the full population (a `j = 0` or `j = 1` swap behaves as a glitch, so provenance is the wrong label for it); a **payoff-trained** probe whose label is `b > a`, where holding actually paid, with its own shuffle; a **three-class** probe over {edit, glitch, quiet} so the false-alarm cost is not an artefact of a probe that never saw one; and the **preamble control**, the world probe read on the state at `t_v - 1`, before the flagged token, split by whether the edit precedes the flag (`t_v == e` events share their whole prefix, so the probe must read exactly 0.500 there -- asserted), with the parent's 2b running-surprisal scalar beside it. Adds every gate's AUC against the hold-better label, which is the ordering a gate actually needs. **Second pass (A5-A6)**: every gate's rank correlation and monotone-invariant binned R^2 against `log(b/a)`, the signed continuous stake -- the direct form of "ordering by the sign is not ordering by the size" -- and a **stake-regression probe**, closed-form ridge with an MLP beside it, trained on `log(b/a)` itself (label-free: it needs only the second forward pass the consumer already runs), refit per subset, reported first as a predictor against the model's own rescaled log Bayes factor and then as a gate with its shuffle. Additive by construction, and the run reports `regression_check`, the max deviation of every A1-A4 scalar from the previous artifact, rather than assuming it. Its Modal image carries an ignore filter for `results/` trees and `.log` files, because a sibling node writing a launch log inside the package makes the build race. |
| `analyze.py` | Local reduction over the JSONs pulled off the volume: every table in [`results/tables.md`](results/tables.md) and the figures in `figs/`. Reads only JSON — no Modal, no GPU. |

## Results and figures

| path | contents |
|---|---|
| `results/tables.md` | The full reduced tables, plus the dated `# Addendum, 2026-09-17` section from `gates2.py` (A1 structural edits, A2 what each gate is ordered on, A3 the three-class probe, A4 the preamble, A5 sign versus size of the payoff, A6 the stake-regression probe). Both are regenerated by one `analyze.py` call. The main sections: the stimulus populations, the imputation comparison, the per-world per-offset prize with the `j` and `k*` breakdowns, the cross-world policy matrix, the lookback bound, the ε venue's two reference columns, the 2e pairs and persistence under each policy, the mixed world with its rate grid, and every gate's separation by offset with the surprisal-matched guard. |
| `results/launch_main.log` | The launch log of the main run (app id, per-arm progress). |
| `figs/{worlds,gates,mixed,lookback}.png` | One figure per question, regenerated by `analyze.py --figs`; PNGs are gitignored under `experiments/`. |
