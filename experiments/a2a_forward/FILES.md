| `reaching/mnist_active_vision_delay.py` | Delayed-feedback causal arm (**null**): command content arrives `content_delay` steps late while the forecast is available immediately (anticipatory injection); FM predicts the clean counterfactual look-update; delay sweep. | `reaching/reaching_vit.py` | `ReachingLoopedViT` — looped ViT as a CONTROLLER for foveal reaching (control-regime port of the "missing `u`"): the command is a displacement ACTION, the fovea position is an endogenous controlled state, the objective is reaching a goal patch. Proprioceptive fovea marker + goal marker each step (+ optional glimpse content distractor when `with_content`); `step` = one recurrent transition; `policy_head` = model-free controller. `ACTION_DELTAS` = {stay,up,down,left,right} |
| `reaching/mnist_reaching.py` | Control-regime causal test (**positive**): foveal reaching. Phase 0 imitation-trains the policy head (model-free ceiling) over random rollouts; Phase 1 freezes the loop, trains a fovea-position probe + `FM_state`/`FM_eff` capacity sweep (efference = a marker at the commanded next fovea `p_{t+1}`); Phase 2 a one-step model-based PLANNER picks actions by rolling the forward self-model (`argmax_a value(s+FM(s,a))`). `planner_eff` reaches the goal while `planner_state` is stuck at random at every capacity, and the shuffled-command control is worst. `--with-content` = large stable command footprint (primary); blank nav = weaker-footprint ablation |
| `reaching/mnist_reaching_internal.py` | Internalized forecasting on reaching (**endogenous self-forecast vs decoupled external planner**): 4 coupling conditions with matched init/coverage — `mf` (model-free = the decoupled operator), `int_plan` (differentiable internal planner, forecast selects actions), `int_inject` (fed-back `gate·FM` input modality, a2a closed-loop analog), `int_plan_state` (arity-1 sanity floor); reading-ladder variants `int_inject_proj` (`CerebellarGate` thalamic-relay projection gate) and `int_inject_readout` (explicit position-decode head on the forecast, still injected). Readout battery: native + decoupled-EXT-planner (fresh FM) behavior, FM veridicality (co-trained vs fresh-frozen Δ-cos), on-traj self-consistency, CKA vs mf, position probe, `cmd_rel_spread`, linear-readout map probe, forecast/injection ablations, + **collusion-vs-selectivity diagnostics** (`subspace_delta_cos` on/off-dir; co-trained FM read by a fresh independent probe). `tag_suffix` param avoids clobbering runs. Headline: internalization makes the operator far more *plannable* (EXT planner +0.55→+1.00, CKA→0.06); map (legible) + model (ablation-critical) coexist; gate opens with dependency. Diagnostics split the couplings — the **planner** forecast is a *transferable task-relevant self-model* (low full-vec Δ-cos is correct selectivity), only the **injection** forecast is a true advisor; arity-1 shows veridicality ≠ usefulness |
| `reaching/curiosity_reaching.py` | **Curiosity Phase 1** (two-timescale value loop — the value-side atom): a content-query world model + teleport policy on a stationary 3-region arena (**struct** fixed digit = reducible / **noise** fresh U(0,1) = irreducible / **blank** = trivial); 4 intrinsic drives (`lp` = `relu(slow−fast EMA ‖e‖)`, `surprise` = +‖e‖, `minsurprise` = −‖e‖, `random`); per-region LP. Headline: LP is *distinguishable* — surprise pins noise (noisy-TV), min-surprise pins blank (dark room), LP alone rides the reducible frontier then *releases* it (noise floor = irreducible 1/12). Leak-proof no-belief WM predicting pixels was load-bearing |
| `reaching/curiosity_drift.py` | **Curiosity Phase 2** (non-stationarity): adds `drift_mode` (`swap` abrupt / `morph` smooth cosine interpolation) content drift of the struct region every `drift_period`; unbiased current-struct-error metric. Naive LP is *worse than random* under abrupt swap (blind to re-opened frontiers, noise fake-LP, forgetting); `morph` fixes the abrupt-jump pathology but LP still can't beat uniform — **no scarcity** (reducible = ⅓ → uniform's 33% suffices) |
| `reaching/curiosity_scarcity.py` | **Curiosity Phase 2b** (scarcity + fresh-FM ensemble): a small reducible **needle** (full-amplitude, morphing) in a large **noise** field + small **blank**; `needle_cols` = scarcity knob; **per-patch** LP (drive must *discover* the needle); adds `disagree` = cross-model variance over K bootstrapped WMs. The ensemble reliably finds the needle (over-samples 3.7×→8.5× uniform, monotone with scarcity) and is best needle-error at every level; naive LP is *partial not broken* (at 5% beats all but disagree) → ensemble is a consistent quantitative win, not a qualitative necessity |
| `reaching/curiosity_reaching_control.py` | **Curiosity → control (v1 substrate attempt; diagnostic record, not a positive result)**: ports the drive to the reaching controller to test disc-4 + re-adaptation under **visuomotor-remap** drift (canonical/intended vs env/realized action→effect map; `slip` = noisy-TV). Headline: deep veridical composition achievable to horizon 8 (maze pos-acc 0.99@n6) but **only on the looped `int_plan` operator** (collapses on `mf`); **veridicality ⊥ control-usefulness** (value-shaped co-trained FM plans best +0.51 despite worst veridicality, beats perfect-sim env-MPC +0.33); maze is **planner-bound not simulator-bound** (perfect sim also floors) |

## Checkpoint compatibility note

**Checkpoint compatibility note**: The `transformer/P_10000000` forward model checkpoint was saved with the original flat `TransformerForwardModel` API (top-level `ln1`, `q_proj`, etc.). The code was later refactored to use `ForwardBlock`/`blocks` for multi-layer support. The analysis scripts (`analyze.py`, `causal_substitution.py`, `behavioral_residual.py`) use a `_LegacyFwdModel` class to load this checkpoint correctly. New checkpoints saved with the current `TransformerForwardModel` will have `blocks.0.*` keys and won't be loadable with the legacy class.
